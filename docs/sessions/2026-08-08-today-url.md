# Today URL Shortcut

## Summary

- Added `/today` as a stable shortcut to the daily view for the current date.
- Resolved the date in the browser so the shortcut follows the device's local timezone.
- Replaced the shortcut URL with the existing canonical `/day/YYYY-MM-DD` route before that route loads the day's todos.

## Behavioral Notes

- `/today` does not load todos independently or duplicate the daily-view implementation.
- Replacement navigation keeps `/today` from becoming an extra browser-history entry.
- Existing dated routes, adjacent-day navigation, and month navigation remain unchanged.

## Verification

- Run `npm run typecheck:web`.
- Run `npm run build:web`.
- Open `/today` and verify the browser navigates to the device-local current date, the daily todos load, and browser Back does not revisit the shortcut.
- Verify direct dated routes and the daily view's previous-day, next-day, and month navigation still work.

## Manual Followup Work

- No environment variables, Supabase migrations, Vercel settings, DNS changes, secrets, or scheduled jobs are required.
